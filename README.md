# unilib

UniLib connects screened TIE Biology, Chemistry and Physics excerpts to an
on-device SQLite vector database, EmbeddingGemma and Gemma 3 1B.

For installation, first-time model setup and offline verification, see
[TIE offline RAG setup](docs/TIE_OFFLINE_RAG.md). This integration targets
Android 11+ ARM64; model downloads need Hugging Face read access once.
